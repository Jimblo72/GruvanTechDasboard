# Mäklargruvan

## Om produkten

AI-marknadsföringsplattform för svenska mäklare, distribuerad via Prowebb med 25% provision. Inkluderar textgenerator, broschyrgenerator (3 mallar: Editorial, Minimal, Classic) och sociala medier-modul med Meta API-integration.

## Planerat att bygga

- [ ] **Brand Pack-integration** — Hexagon-logotyp + wordmark i alla moduler
- [ ] **Inbyggt hjälpsystem** — Klickbar hjälp per sektion i höger sidopanel, AI-chat för komplexa frågor
- [ ] **Värderingswidget + Hemnet-bevakning** — Unik URL per mäklare, AI-värdering, QR på broschyr, RSS-bevakning
- [ ] **Meta Lead Ads** — "Vad är din bostad värd?" via sociala medier-modulen
- [ ] **Settings-panel** — Namn, kontor, logo, kontaktinfo i localStorage (mg_settings)
- [ ] **Mspecs-integration** — Adapter-lager med fromMspecs()/toMspecs() — ej strukturell omskrivning
- [ ] **Planritningsverktyg** — Konva.js i separat planritning.html, post-launch
- [ ] **Spotify-integration** — Mini-player + stämningsanpassade spellistor (Fas 2)
- [ ] **AI-inspelningsfunktion** — Whisper-baserad inspelning och transkribering av röstmemon och kundsamtal med automatisk renskrivning och integration i systemet
- [ ] **Offertgenerator** — Offertmallar som genereras som både html fil och pdf.
