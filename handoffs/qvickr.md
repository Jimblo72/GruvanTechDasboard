# Qvickr

## Om produkten

Qvickr är en plattform med fem produkter för konsumentaggregering på fragmenterade marknader. Qvickr All (andrahandsmarknader) är live i Chrome Web Store. Högst exitpotential i portföljen — strategiska köpare: Adevinta och Schibsted. Webb-first är primär strategi; Chrome-extensionen är power-user-uppgradering.

## Planerat att bygga

- [ ] **Qvickr All — webb-app** — aggregator.html driftsätts på qvickr.com med Supabase-backend och Stripe
- [ ] **Qvickr Post** — Cross-posting till flera andrahandsmarknader — kommer snart
- [ ] **Qvickr Bostad** — Bostadssök + boendekalkyl. Planerad Q4 2026. Konfidentiellt — Hemnet ska ej få förvarning
- [ ] **Qvickr Auto** — Bilsök cross-platform. Framtid. Konfidentiellt
- [ ] **Qvickr Båt** — Båtsök cross-platform. Framtid
- [ ] **SEO-landningssidor** — Per kategori och stad för organisk tillväxt
- [ ] **Adevinta-pitch** — När reell webbtrafik + data finns att visa upp
