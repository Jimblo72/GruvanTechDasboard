# Körjournal

## Om produkten

Lokal HTML-app för att importera och hantera körjournaler från Automile. Stöder CSV och Excel-import från app.automile.com. Klassificering av resor som tjänst/privat med automatisk igenkänning baserat på adresser. Excel-export via SheetJS för skatteändamål.

## Planerat att bygga

- [ ] **Automatisk klassificering** — Förbättra igenkänning av återkommande adresser
- [ ] **Skatteverket-export** — Format anpassat för digital inlämning
