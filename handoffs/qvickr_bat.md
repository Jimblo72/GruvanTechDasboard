# Qvickr Båt

## Om produkten

Båtsök cross-platform som aggregerar från Blocket Båtar, Barnebys och specialiserade båtmarknader. Naturlig synergi med Gruvanbåt — Qvickr Båt hanterar sökupplevelsen, Gruvanbåt hanterar dokumentation och historik.

## Planerat att bygga

- [ ] **Aggregering** — Blocket Båtar + specialiserade båtmarknader
- [ ] **Synergi** — Koppla mot Gruvanbåt för historikdata på specifika objekt
- [ ] **Timing** — Sist i Qvickr-serien — efter All, Post, Bostad och Auto
