# Saga

## Om produkten

AI-driven produkt som automatiskt bygger upp en persons livsberättelse via kopplingar till Google Photos, sociala medier, Spotify och kalender. Fysisk metallplatta med QR-kod placeras vid gravsten och leder till en interaktiv sammanfattning. Kanal: pensionsbolag som erbjuder produkten som en benefit till sina kunder.

## Planerat att bygga

- [ ] **Domän** — mysaga.se (kolla tillgänglighet) — obs kollision med mysaga.com (DNA-bolag)
- [ ] **B2B2C-modell** — Pensionsbolag som distributionskanal — längre säljcykel men bredare volym
- [ ] **Datakopplingar** — Google Photos, Spotify, kalender, sociala medier
- [ ] **Metallplatta** — Engångsprodukt vid "avslut" — 500-1000 kr, QR-kod till digital profil
- [ ] **Monetisering** — Prenumeration löpande + engångsköp vid export (fysisk bok, PDF, interaktivt minne)
