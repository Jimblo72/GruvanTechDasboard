Systemflöde
Silver är rådata, koppar är maskineriet, guld är det förädlade resultatet. Klicka en nod för att simulera en händelse — en röd, andande nod betyder att något väntar på dig.
⛏ Malm bearbetat idag: 0
Klicka direkt på en nod i grafen för att kvittera en väntande händelse (röd puls). Knapparna ovan simulerar normala flöden.
Koppla till riktiga funktioner
// Flöde — en händelse passerar genom systemet
window.GruvanFlow.trigger('outlook');

// Uppmärksamhet — något väntar på godkännande
// (t.ex. mailutkast redo, SMS med känsligt innehåll flaggat)
window.GruvanFlow.attention('outlook', true);
// … och när det kvitterats/skickats:
window.GruvanFlow.attention('outlook', false);

// Exempel: Supabase Realtime styr båda automatiskt
supabase
  .channel('pipeline')
  .on('postgres_changes', { event: 'INSERT', table: 'mail_events' },
      () => window.GruvanFlow.trigger('outlook'))
  .on('postgres_changes', { event: 'INSERT', table: 'pending_approvals' },
      row => window.GruvanFlow.attention(row.new.node, true))
  .subscribe();

Nod-id: claude-code, gemini, github, netlify, outlook, sms, supabase, maklargruvan. attention() är avsiktligt icke-automatisk — den rensas bara av attention(id, false) eller ett klick i grafen, aldrig av en timer. Precis som godkännandeflödet i övrigt ska inget kvitteras av sig självt.
